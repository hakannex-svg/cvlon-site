# Civilon Price Check Quick Start

> [!IMPORTANT]
> AI does not determine market price. AI output is a proposal. Human review is required, and the deterministic engine calculates the observed range and classification.

## Daily flow

**New Price Check → Assign → Review submission → Review clean document → Extract if useful → Confirm/create revision → Select comparables → Create analysis → Draft explanation → Human review → Preview result → Approve → Send → Follow sourcing opportunity if requested**

1. Sign in at `/admin/login`; open `/admin/price-checks`.
2. Triage new/old unassigned requests and assign ownership.
3. Compare the immutable original with the current revision.
4. For uploads, wait for **Clean**. Never open/extract Pending, Rejected, or Failed files.
5. If extraction helps, review the proposed line and every field; choose **Accept proposal** or **Keep current**.
6. Create an immutable revision with a factual change reason. Confirm part/dash number, condition, transaction, currency, price components, core, quantity, date, and documents.
7. Include/exclude each governed comparable with a reason. Do not expose raw evidence or provenance.
8. Create the deterministic analysis. Verify low/median/high, warnings, classification, and confidence reason.
9. Draft manually or request an AI proposal. Apply/edit/regenerate/discard; re-review every word.
10. Preview the exact customer result. Use only Below/Within/Above Observed Range or Insufficient Comparable Evidence.
11. Reviewer/Admin approves. Any material change requires a new approval.
12. Send; verify Postmark success. Approved is not Sent.
13. If **Get a Civilon Quote** is selected, follow the single linked sourcing opportunity.

## Stop checks

- Never say “overpaid,” “ripped off,” supplier wrongdoing, cost, or margin.
- Never call the result an appraisal, valuation certificate, guaranteed fair market value, or comprehensive market search.
- Never disclose raw comparables, identities/provenance, analyst notes, AI metadata, cookies, tokens, or secure links.
- A refundable core is exposure, not price; a forfeited core is a separate known cost context.
- Zero/one eligible observation does not support a displayed range. Two observations require a visible limitation.
- No automatic FX conversion; mixed currency must be resolved by evidence selection.
- Keep original submissions, revisions, analyses, results, AI artifacts, and audit events immutable.
